# 調味料ラップバトル

醸造調味料の5種が、城下町を舞台にラップで張り合う遊びのページです。対戦カードを2枚選ぶと、名勝負の歌詞を組み替えてバトルが出ます。

- 遊ぶ: https://y-kanno-sakenote.github.io/chomiryo-rap-battle/
- キャラ: 醤油／味噌／みりん／食酢／清酒（料理酒として）

## 歌詞について

- 歌詞はAI（Claude）で書いたものです。`docs/chomiryo_corpus.jsonl` の名勝負から、同じ相手・同じ韻の2行ずつを組み替えて表示します
- 調味料についての話は、日本醸造協会誌の記事などの資料にもとづく範囲に絞っています
- なかま: [醸造ラップバトル](https://jozorap.sakenote.net/)／[ワインラップバトル](https://y-kanno-sakenote.github.io/wine-rap-battle/)
- 作成: 合同会社サケノテ（sakenote.net）
